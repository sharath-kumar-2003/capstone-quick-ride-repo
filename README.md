## 📌 Overview

**Quick Ride** is a full-stack ride-booking web application inspired by platforms like Uber and Ola. It allows users to book rides, drivers to accept requests, and administrators to manage the entire platform.

The project was developed as a **Capstone Project** using the **MERN Stack**, providing real-time ride management, secure authentication, and an intuitive user experience.

---

## ✨ Features

### 👤 User Module
- User Registration & Login
- Secure Authentication
- Book a Ride
- Select Pickup & Drop Locations
- Fare Estimation
- Ride History
- Profile Management

### 🚗 Driver Module
- Driver Registration & Login
- Accept/Reject Ride Requests
- Ride Status Updates
- Earnings Dashboard
- Driver Profile

### 🛠️ Admin Module
- Dashboard Overview
- Manage Users
- Manage Drivers
- Monitor Rides
- System Statistics

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/sharath-kumar-2003/capstone-quick-ride-repo.git

cd capstone-quick-ride-repo
```

---

## 📦 Install Dependencies

### Backend

```bash
cd Backend
npm install
```

### Frontend

```bash
cd Frontend
npm install
```

---

## ⚙ Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

GOOGLE_MAPS_API_KEY=your_google_maps_api_key

EMAIL=your_email

PASSWORD=your_email_password
```
